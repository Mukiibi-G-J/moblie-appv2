# Additional Features for Home Screen

## Current Features ✅
1. Header (Welcome, User, Date, Store Status)
2. KPI Cards (Revenue, Orders, Products Sold, Low Stock)
3. Quick Actions (Permission-based)
4. Recent Transactions

## Recommended Additional Features

### 1. **Draft Sales Section** (High Priority)
- Show pending draft sales that need completion
- Max 3 drafts (as per system limit)
- Quick access to resume/complete drafts
- Shows: Invoice No, Customer, Amount, Date
- Permission: Sales module + Create permission

### 2. **Pending Payments/Outstanding Receivables** (High Priority)
- Total outstanding customer balances
- Count of customers with outstanding payments
- Quick access to payments/customers
- Permission: Payments/Customers module

### 3. **Today's Activity Summary** (Medium Priority)
- Average order value
- Top customer today
- Most sold item today
- Payment method breakdown

### 4. **Quick Stats Cards** (Medium Priority)
- Total Customers (if customers module)
- Total Items in Inventory
- Cash vs Card payments today
- Refunds/Returns count

### 5. **Alerts & Notifications** (Medium Priority)
- System notifications
- Important updates
- Maintenance alerts

### 6. **Top Selling Items Today** (Low Priority)
- List of top 3-5 items sold today
- With quantities sold
- Quick access to item details

## Implementation Priority

1. **Draft Sales** - Very useful for cashiers, shows incomplete work
2. **Outstanding Receivables** - Important for managers/owners
3. **Today's Activity Summary** - Nice to have insights
4. **Quick Stats** - Additional context
5. **Top Selling Items** - Nice to have
